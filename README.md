# Workshop (v 3.6.1)

Рабочее место производственного персонала для учёта рабочего времени и изготовления оконных конструкций (прямоугольных и полукруглых рам/створок).

## Описание

Настольное приложение на Python с графическим интерфейсом (Tkinter) для:

- **Учёта работников** — регистрация начала и окончания смены, перемещение между рабочими местами, автоматическое закрытие «зависших» сессий за прошлые дни.
- **Регистрации деталей и изделий** — сканирование штрих-кода, проверка принадлежности к разрешённой группе рабочего места, контроль дубликатов, расчёт габаритов, периметра и площади (включая арочные/полукруглые конструкции).
- **Отображения чертежей** — автоматический показ изображений конструкций из сетевой папки с обрезкой полей и адаптивным масштабированием.
- **Статистики смены** — подсчёт количества уникальных изделий, суммарного периметра (м) и площади (м²) за текущую смену.
- **Мониторинга и отказоустойчивости** — визуальный индикатор состояния сети, БД и сетевой папки с чертежами, автопереподключение при обрывах связи и автовыключение ПК при простое в конце дня.


## Управление и бизнес-логика

| Действие / Событие | Описание работы |
|--------------------|-----------------|
| **Вход / выход сотрудника** | Сканирование штрих-кода с префиксом `2200`: открывает сессию на текущем месте, закрывает при повторном сканировании или переводит с другого рабочего места (при наличии свободных слотов `RAB_MAX`). |
| **Регистрация детали** | Сканирование кода детали из `CCALC`. Для рабочих мест `GR` 1–2 разрешены только рамы (`r`), для `GR` 3–4 — только створки (`s`), для `GR` 5–6 — оба типа с контролем уникальности по `BCI`. Группа `3` (импост) игнорируется. |
| **Расчёт геометрии** | Из длин деталей вычитается `6 мм`. Для прямоугольных изделий (`ORIENT` = `В` и `П`) считается $P = 2(w + h)$, $S = w \cdot h$. Для полукруглых (`DUGA = 1`, `ORIENT` = `В` и `Н`) считается $P = L_Н + L_В$, $S = \frac{L_Н^2 \cdot \pi}{8}$. |
| **Индикатор статуса** | Квадрат в левом нижнем углу: **зелёный** — БД и папка чертежей доступны; **жёлтый** — нет доступа к сетевой папке чертежей; **красный** — потеряна связь с БД. |
| **Выключение ПК** | Сканирование кода `12345` закрывает все активные сессии на рабочем месте и выключает компьютер (`systemctl poweroff` / `shutdown -t 00 -S`). |
| **Автовыключение по простою** | После `17:00`, если на рабочем месте есть открытые сессии, но в течение `1 часа` не зарегистрировано ни одной детали, сессии принудительно закрываются временем последней детали и ПК выключается. |


# Workshop (v 4.0.0)

Терминал производственного персонала для учёта рабочего времени и регистрации изготовления оконных конструкций (прямоугольных и полукруглых рам/створок).

## Описание

Настольное приложение на Python с графическим интерфейсом (Tkinter), построенное по слоистой архитектуре с разделением ответственности между слоем данных, бизнес-логикой и UI:

- **Учёт работников** — регистрация начала и окончания смены, перемещение между рабочими местами с проверкой лимита мест (`RAB_MAX`), автоматическое закрытие «зависших» сессий за прошлые дни.
- **Регистрация деталей и изделий** — сканирование штрих-кода, проверка принадлежности к разрешённой группе рабочего места (`GR`), защита от дубликатов (с возможностью повторного сканирования для просмотра чертежа и размеров), расчёт габаритов, периметра и площади (включая арочные/полукруглые конструкции).
- **Неблокирующее отображение чертежей** — фоновая загрузка изображений конструкций из сетевой папки (SMB) в отдельном потоке с обрезкой полей и адаптивным масштабированием без «фризов» интерфейса.
- **Статистика смены** — подсчёт количества уникальных изделий, суммарного периметра (м) и площади (м²) за текущую смену.
- **Мониторинг и отказоустойчивость** — фоновая проверка состояния сети, БД и сетевой папки с чертежами, визуальный индикатор статуса, автоматическое управление транзакциями и автовыключение ПК при простое в конце дня.
